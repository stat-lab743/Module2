# Lab 4: From Sample to Population

Three-part randomized lab targeting 20–25 minutes. Includes 144 reproducible scenario IDs, standard error and z calculations, upper-tail probability lookups, and three short responses. The Concept Connection section has been removed.

Generate My Studies selects a new scenario. Load scenario ID restores its study values. Entries are not saved. All study means exceed the reference mean, and all generated z values are within the included unit normal table. Different students can receive the same scenario; uniqueness is not guaranteed.

The table provides P(Z ≥ z), with instructions for textbook tables that show left-tail or mean-to-z areas. Probabilities refer to sample means under the reference population. A normal population and independent observations are explicit assumptions.
