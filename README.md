# Lab 4: From Sample to Population

Revised short version: three parts targeting about 20 minutes. Students calculate SE and z for M = 54 with n = 9, 36, and 144, using μ = 50 and known σ = 12. They submit one table, calculation work, and three short responses. Timing is an estimate, not classroom-tested.

The normal reference population and independent observations are explicit assumptions, allowing the normal model at n = 9. This is a bridge to inference, not a full hypothesis-testing or t-test assignment.

Extract the package and open index.html. Keep style.css and lab.js beside it. Student directions are in student-instructions.md. The page provides calculation feedback and three theoretical sampling-distribution views. It does not save or submit answers.

For a new GitHub Pages repository, upload index.html, style.css, and lab.js to the publishing root. In Settings → Pages, choose Deploy from a branch and the branch/root containing these files. Copy the published URL into the student directions. Do not overwrite another site's homepage unintentionally.
